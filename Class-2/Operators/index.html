Types of Operators :

  1. Arithmatic Operator
  2. Assignment Operator
  3. Comparision Operator
  4. Logical Operator

1 - Arithmatic Operator : It does the simple calculations like addition, subtraction, multiplication, division and modolus.

  • such as + | - | * | / | %

2 - Assignment Operator : It is not too different from arithmatic operators. we use this one to avoid reasign. After assigning var a number, we won't recall it to add some other numbers too. instead we assignment operators.

  • such as = | += | -= | /= | *=

3 - Comparision Operator : It only gives answer in boolean form, either the statment gets true of false.

  • such as | > | < | == | === | != | !== | >= | <=

4 - Logical Operator : It also gives answer is boolean form, either the statment gets true of false.

  • such as && and ||

Function and Prompt :

Function () : This is the symbol for alert. We use alert to show a pop-up. The moment someone opens our website, the alert will show our message.

Prompt : prompt - It is also used for pop-ups, but the only difference is that we use prompt to take their data instead of showing them. Note: we used this with variables.

Concatenation and Addition :

Addition : It is when we add two or more numbers together and its sum is called addition.

concatenation : It happens when your two different data types together, like string used with number. instead of getting the sum we find them written together.
